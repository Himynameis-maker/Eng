# 英語長文生成 README（AI向け）

`reading.html` の **`<script id="data" type="application/json">` ブロックだけ** を差し替えて、新しい長文ページを作る。CSS・JS・HTML構造は変更しない。

## 画面仕様（変更不可）
- 上部固定バー：「英単語表」「マーカー」のオン/オフボタン。
- 本文：タイトル＋10〜13行の英文（1文＝1行、行番号付き）。
- 少しスクロールすると和訳が現れ、以後は消えない。
- 英単語表ボタン：画面が単語表に切り替わる（再度押すと本文に戻る）。
- マーカーボタン：文法的なつながりに色が付き、各行の下に解説が出る。

## 生成手順
1. **抽選**：`random_iso.html` の `ISO` 配列（249件）から、9カテゴリへ重複なしで割り当てる。
   カテゴリ：1国の文化 2海 3山 4ハイテク 5環境保全 6偉人 7虫 8動物 9植物
   ```python
   import re, random
   iso = re.search(r'const ISO = "([^"]+)"', open('random_iso.html').read()).group(1).split()
   cats = ["国の文化","海","山","ハイテク","環境保全","偉人","虫","動物","植物"]
   rng = random.SystemRandom()
   draw = [{"n":i+1,"cat":c,"iso":k} for i,(c,k) in enumerate(zip(cats, rng.sample(iso, 9)))]
   selected = rng.randint(1, 9)   # 使うカテゴリ番号も乱数で決める
   ```
2. **テーマ決定**：`selected` で出たカテゴリ×国を **そのまま使う**。AIが選んだり、書きやすい組み合わせが出るまで引き直したりしない。
   ユーザーがカテゴリや国を指定した場合のみ、それに従う。国名は英語表記で `country` に入れる。
   国とカテゴリが噛み合わなくても引き直さず、その国らしい切り口（歴史・地理・暮らしなど）を探して書く。
3. **本文作成**（下記ルール）→ 和訳 → 英単語 → マーカー付与。
4. データブロックを差し替え、下記チェックリストで確認してから納品する。

## 本文ルール
- 高校レベル（CEFR B1〜B2）。**10〜13文**、1文12〜22語、全体150〜230語程度。
- 事実は正確に。数値に自信がなければ「a few thousand」のように曖昧に書く。
- 1つの文章の中に、関係詞・不定詞・分詞（後置修飾）・受動態・完了形・`so ～ that`・`not only ～ but also` など、**文法項目を多様に**入れる。
- 和訳は自然な日本語。直訳しすぎない。

## JSONスキーマ
```json
{
  "draw": [{"n":1,"cat":"国の文化","iso":"AU"}, ...9件],
  "selected": 8,
  "country": "Thailand",
  "title": "…",
  "lines": [
    {"en":"マーカー記法つきの英文", "ja":"和訳", "notes":[[グループ番号,"解説"], ...]}
  ],
  "vocab": [["lemma","品詞","意味",行番号,"本文中の語形"], ...]
}
```

## マーカー記法
`[[グループ番号|ラベル|テキスト]]`
- グループ番号は **1〜4**。同じ文の中で **同じ番号＝つながっている語句**（同色になる）。
  例：主語と動詞 `[[1|主語|The number]] … [[1|動詞|has dropped]]`、先行詞と関係詞 `[[2|先行詞|forests]], [[2|関係詞|which]]`。
- ラベルは短く（例：主語 / 動詞 / 先行詞 / 関係詞 / 接続 / 呼応 / 後置修飾 / 目的 / 条件）。
- **入れ子にしない。** `|` や `]` を本文に含めない。
- 1文につき1〜4グループ。`notes` の番号は本文のグループ番号と対応させ、各グループ最大1行で簡潔に解説する。
- 使う文字：アポストロフィと引用符は `’` `“ ”`（JSONの構文以外は直線の `'` `"` を使わない）。

## 英単語（vocab）
- **10〜14語**。その文章の理解に重要な語を選ぶ（高校〜大学入試レベル中心）。
- 要素は `[原形, 品詞, 意味, 行番号, 本文中の語形]`。**語形は、その行の本文に綴りどおり含まれていること**（`centuries` など）。

## 納品前チェックリスト
- [ ] `lines` が10〜13件
- [ ] 各 `en` の `[[ ]]` が閉じており、入れ子なし。グループ番号が1〜4
- [ ] `notes` の番号が、その行に存在するグループ番号と一致
- [ ] `vocab` の語形が指定行に存在
- [ ] `selected` が `draw` の `n` に存在し、タイトル・本文がテーマ／国と合っている
- [ ] JSONとして有効（末尾カンマなし）
